# DevSystem governance distribution

Public distribution of accepted DevSystem governance releases, compatibility
metadata, and migration definitions.

This repository is an optional, read-only upstream for projects generated by
DevSystem. Generated projects contain their complete installed governance and
remain usable when this repository or the network is unavailable. Each project
repository remains authoritative for its active governance; publication here
does not modify or override a project.

## Releases and compatibility

- `releases.json` is the machine-readable release manifest.
- `CHANGELOG.md` explains the governance meaning and impact of each release.
- `migrations/` defines only explicitly supported, version-specific migrations.

A release's `migrates_from` array lists installed baselines with a supported
migration path. Its `migration` value identifies the applicable definition.
An empty list or absent path means manual review is required; compatibility is
never inferred from version ordering.

Synchronization requires explicit authorization in the governed project,
complete validation, and a reviewable repository change. Discovery itself is
read-only.

## Publication workflow

Accepted DevSystem governance change → version established in DevSystem →
distribution manifest, history, and migration material prepared → validation →
reviewed pull request → Product Owner merge → public discovery.

DevSystem remains authoritative for governance development and acceptance.
Released history is append-only in meaning: material changes require a new
governance release rather than rewriting an existing release.
